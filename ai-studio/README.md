# 🎬 סטודיו AI – תמונות וסרטונים מהטלפון

| קובץ | תפקיד |
|---|---|
| `colab_server.py` | השרת שרץ ב-Google Colab (מודלים SDXL-Turbo ו-LTX-Video) |
| `index.html` | אפליקציית הטלפון (עברית, RTL) |

## הפעלה (פעם אחת בכל פעם שעובדים)
1. פתחו את https://colab.research.google.com וצרו מחברת חדשה (New notebook).
2. בתפריט בחרו **Runtime ← Change runtime type ← T4 GPU** ושמרו.
3. העתיקו את **כל** התוכן של `colab_server.py` לתא אחד ולחצו ▶️.
4. המתינו. בפעם הראשונה ההורדה וההכנה לוקחות כ-10–15 דקות. בסוף יופיע קישור בסגנון `https://xxxx.gradio.live`.
5. העתיקו את הקישור.

## בטלפון
1. הורידו את `index.html` לטלפון ופתחו אותו בדפדפן (Chrome / Safari).
2. הדביקו את הקישור בשדה העליון ולחצו **"בדוק חיבור"**. צריך להופיע "מחובר". הקישור נשמר אוטומטית בדפדפן.
3. **יצירת תמונה:** כתבו תיאור (אפשר בעברית), בחרו יחס תמונה ולחצו "צור תמונה". אחר כך אפשר ללחוץ "הורד לגלריה" או "הפוך לסרטון".
4. **סרטון:** בחרו תמונה מהגלריה (או העבירו את התמונה שנוצרה), כתבו תיאור תנועה, בחרו משך (5–60 שניות) ולחצו "צור סרטון". מד ההתקדמות מראה איזה מקטע מעובד כרגע.

## חשוב לדעת
- השאירו את לשונית ה-Colab פתוחה בזמן העבודה. הקישור משתנה בכל הפעלה מחדש.
- **זמני עיבוד ב-T4 חינמי:** תמונה לוקחת שניות. סרטון לוקח כ-3–6 דקות לכל 5 שניות, כך ש-60 שניות יכולות לקחת עד שעה. מצב "מהיר" מהיר יותר.
- אם החיבור נופל באמצע סרטון, היצירה ממשיכה בשרת. רעננו את הדף כדי להמשיך במעקב.
- אם Colab מנתק אתכם (מגבלת זמן חינמית), הריצו את התא שוב וקבלו קישור חדש.
