# כושר-טיל — שרת ניהול (Cloudflare Workers + D1)

שרת קטן שמנהל את מצב הסינון של כל מכשיר, ופאנל ניהול למנהל (משתמש + סיסמה).
רץ על המסגרת החינמית של Cloudflare — תמיד פעיל, בלי כרטיס אשראי.

## מה זה עושה
- **API למכשירים** (קריאה בלבד): האפליקציה שואלת "מה המדיניות שלי?" והשרת עונה
  פעיל/כבוי/חלון-שחרור. מכשיר **לא יכול** לכבות את עצמו דרך ה-API.
- **פאנל ניהול** (`/panel`): רשימת מכשירים, הדלקה/כיבוי, שחרור זמני (15 דק'—יום),
  תיוג מכשיר + טלפון מנהל, ואישור בקשות שחרור.

---

## העלאה — שלב אחר שלב (≈5 דקות, חינם)

דרוש Node.js מותקן במחשב (nodejs.org).

```bash
cd kosher-til-server
npm install                 # 1. מתקין את כלי Cloudflare (wrangler)
npx wrangler login          # 2. התחברות — נפתח דפדפן, צור חשבון Cloudflare חינמי

npx wrangler d1 create kosher_til   # 3. יוצר מסד נתונים — העתק את ה-database_id שמוצג
# פתח wrangler.toml והחלף את REPLACE_WITH_YOUR_DATABASE_ID ב-id שקיבלת

npm run db:init             # 4. יוצר את הטבלאות במסד
npm run deploy              # 5. מעלה! תקבל כתובת כמו:
#   https://kosher-til-server.<השם-שלך>.workers.dev
```

### אחרי ההעלאה
1. היכנס לכתובת שקיבלת — תועבר ל-`/setup`.
2. צור **שם משתמש וסיסמה** למנהל (פעם אחת; אחר כך העמוד נעול).
3. מעכשיו תתחבר ב-`/login` ותנהל ב-`/panel`.

## חיבור האפליקציה לשרת

בקובץ `kosher-til-android/app/build.gradle.kts`, ב-`defaultConfig`, הכנס את
הכתובת שקיבלת:

```kotlin
buildConfigField("String", "DEFAULT_SERVER_URL", "\"https://kosher-til-server.<השם-שלך>.workers.dev\"")
```

בנה מחדש את האפליקציה. מעכשיו כל מכשיר שיפעיל את הסינון יופיע אוטומטית בפאנל
(אחרי הסנכרון הראשון — עד 15 דקות, או מיידית בפתיחת האפליקציה).

---

## מסגרת חינמית (Cloudflare)
- Workers: 100,000 בקשות ליום — בחינם. מכשיר פונה כל ~15 דק', אז זה מספיק
  לאלפי מכשירים.
- D1: עד 5GB ו-5 מיליון קריאות/יום בחינם.
- אין "שינה" ואין צורך בכרטיס אשראי.

## אבטחה — המלצות לייצור
- **הסיסמאות** מאוחסנות עם PBKDF2 (100k סיבובים) — לא בטקסט גלוי. ✔
- **מומלץ להוסיף** חתימה על תגובת המדיניות (כדי שלא ניתן יהיה לזייף "כבוי" עם
  שרת מתחזה). ראו `README` הראשי של האפליקציה.
- שקול הגבלת קצב (Cloudflare Rate Limiting) על `/api/admin/login`.
