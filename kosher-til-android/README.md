# כושר-טיל — אפליקציית סינון תוכן לאנדרואיד

אפליקציית סינון תוכן בסגנון "טלפון כשר" (כמו נטסמארט/נטספארק, Rimon וכו'),
בנויה מאפס ובאופן **מקורי** — ללא קוד, מותג או נכסים של אף ספק קיים.

> ⚠️ **גילוי נאות על אבטחה:** אי אפשר לבנות אפליקציה *באמת* "בלתי ניתנת לפריצה"
> או "בלתי ניתנת להסרה" על טלפון שנמצא פיזית ביד המשתמש. מה שהאפליקציה הזו
> עושה הוא מה שעושים כל שירותי הסינון הלגיטימיים: **מרתיעה ומקשה** על עקיפה
> והסרה. ראו "מגבלות אבטחה" למטה. בנייה של כלי שמנסה להסתתר מהמשתמש או למנוע
> הסרה *בניגוד לידיעתו* אינה המטרה כאן — האפליקציה גלויה, בהסכמה, והמשתמש יודע
> שהיא מותקנת.

## מה כבר בנוי (אפליקציית האנדרואיד)

| רכיב | קובץ | תפקיד |
|------|------|-------|
| VPN מקומי לסינון DNS | `vpn/FilterVpnService.kt`, `vpn/Dns.kt` | חוסם דומיינים אסורים ברמת ה-DNS (0.0.0.0), מעביר הלאה שאילתות מותרות |
| שירות נגישות | `access/BlockAccessibilityService.kt` | חוסם אפליקציות וכתובות בדפדפן, ושומר מפני כניסה למסכי הסרה |
| מנהל התקן (Device Admin) | `admin/KosherAdminReceiver.kt` | מקשה על הסרת האפליקציה |
| שכבת מדיניות מרוחקת | `data/PolicyClient.kt`, `data/FilterController.kt` | מושכת מדיניות מהשרת (פעיל/כבוי/חלון שחרור), fail-closed |
| פתח תחזוקה (פיתוח) | `lock/MaintenanceManager.kt`, `lock/MaintenanceActivity.kt` | קוד `א.י.ס.חסימות` לכיבוי והסרה בזמן פיתוח |
| מסך חסימה | `lock/BlockActivity.kt` | מוצג בעת גישה לתוכן חסום; מאפשר **בקשת שחרור מהמנהל** בלבד |
| מסך ראשי | `ui/MainActivity.kt` | סטטוס, אשפי הרשאות, כניסה נסתרת לתחזוקה |
| אחסון מוצפן | `data/Prefs.kt` | EncryptedSharedPreferences |

### מודל השחרור (כמו נטסמארט)
- **המשתמש במכשיר אינו יכול לשחרר/לכבות את עצמו.** השחרור מגיע **מהשרת** בלבד.
- מסך החסימה מאפשר רק **לבקש** שחרור; המנהל מאשר מרחוק (`unlockUntil` במדיניות).
- **פתח תחזוקה לפיתוח:** הקשה 7 פעמים על הכותרת "כושר-טיל" במסך הראשי פותחת
  מסך נסתר. הזנת הקוד `א.י.ס.חסימות` מכבה את הסינון ומסירה את ה-Device Admin
  כדי שאפשר יהיה להסיר את האפליקציה. מבוטל בגרסת ייצור (ראו למטה).

## בנייה והרצה

דרוש **Android Studio** (Koala/2024+), **JDK 17**, ו-Android SDK 34.

```bash
# מתוך תיקיית kosher-til-android:
# 1. פתחו את התיקייה כפרויקט ב-Android Studio (הוא יוריד Gradle 8.9 אוטומטית), או:
gradle wrapper --gradle-version 8.9   # פעם אחת, ליצירת gradle-wrapper.jar
./gradlew assembleDebug                # בונה APK ל-app/build/outputs/apk/debug/
```

> הקבצים לא מכילים את `gradle-wrapper.jar` הבינארי. Android Studio ייצר אותו,
> או הריצו `gradle wrapper --gradle-version 8.9` פעם אחת.

התקנה למכשיר:
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

לאחר ההתקנה, במסך הראשי: אשרו לפי הסדר את ה-VPN, הנגישות, ה-Overlay,
ה-Device Admin וההתראות.

## כיבוי פתח התחזוקה בייצור

בקובץ `app/build.gradle.kts`, ב-`defaultConfig`:
```kotlin
buildConfigField("boolean", "MAINTENANCE_ENABLED", "false")
```
ואז הקוד `א.י.ס.חסימות` לא יעבוד יותר, והשחרור יתאפשר **רק דרך השרת**.
אפשר גם לכבות אותו מרחוק בשדה ייעודי (ראו `Prefs.disableMaintenanceForever`).

## השרת (השלב הבא — טרם נבנה)

האפליקציה מצפה ל-API הבא (REST/JSON). זהו ה"פאנל ניהול" של נטסמארט:

```
GET  /api/device/{deviceId}/policy
  → 200 { "version": 7, "enabled": true, "unlockUntil": 0, "managerContact": "050-..." }

POST /api/device/{deviceId}/unlock-request
  body { "deviceId": "...", "reason": "...", "ts": 1700000000000 }
  → 200
```

- `enabled=false` או `unlockUntil > now` → הסינון כבוי/משוחרר זמנית.
- יש להעלות `version` בכל שינוי; האפליקציה מתעלמת מגרסאות ישנות.
- **האפליקציה fail-closed:** אם השרת לא זמין, נשמרת המדיניות האחרונה.
- מומלץ: אימות הדדי (mTLS) או חתימת מדיניות, כדי שלא ניתן יהיה לזייף תגובת "כבוי".

## מגבלות אבטחה (קראו את זה)

1. **Device Admin הוא הרתעה, לא נעילה מוחלטת.** משתמש עם המכשיר ביד יכול
   להיכנס ל-Safe Mode, לבטל את המנהל, או לעשות Factory Reset.
2. **אכיפה אמיתית דורשת Device Owner.** זה מושג רק בהקצאה (provisioning) של
   מכשיר חדש/מאופס דרך QR או EMM. אז אפשר למנוע הסרה, להגביל הגדרות ולחסום
   Safe Mode. זהו המודל של "מכשיר כשר" אמיתי מהיצרן.
3. **סינון DNS נעקף** ע"י DNS-over-HTTPS בתוך אפליקציות, VPN אחר, או שינוי DNS.
   לכן יש שכבת נגישות משלימה — אך גם היא מוגבלת.
4. **אנדרואיד מאפשר VPN פעיל אחד בלבד.** הפעלת VPN אחר תנתק את הסינון
   (`onRevoke` מנסה לשחזר).
5. IPv6 אינו מיורט בגרסה זו — יש להוסיף לפני ייצור כדי למנוע עקיפה.

ההמלצה: לייצור אמיתי יש לשלב **Device Owner provisioning** + רשימות חסימה
מתעדכנות מהשרת + IPv6.
