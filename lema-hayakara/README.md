# לאמא היקרה 🧵❤

אפליקציה לאנדרואיד ול-Windows שממירה תמונות, לוגואים, קובצי PDF ו-SVG, תמונות צילום וטקסט בכל שפה לקובצי רקמה למכונה (DST למכונות SWF, וגם PES, JEF ו-EXP).
הכול עובד על המכשיר עצמו, בלי אינטרנט. גם הבינה המלאכותית רצה מקומית.

## הורדה והתקנה

את הקבצים מורידים מעמוד ה-**Releases** של הריפו (הגרסה העליונה היא החדשה):

- **אנדרואיד:** מורידים את `LeImaHayakara-N.apk` ופותחים אותו. בפעם הראשונה הטלפון ישאל אם לאפשר התקנה ממקור לא ידוע – מאשרים.
- **Windows:** מורידים את `LeImaHayakara-Setup-….exe` ולוחצים עליו פעמיים. אם מופיעה אזהרה כחולה ("Windows הגן על המחשב"), לוחצים "מידע נוסף" ואז "הפעל בכל זאת".

### עדכונים
- **Windows:** האפליקציה מורידה עדכונים לבד ושואלת אם להפעיל מחדש.
- **אנדרואיד:** פעם ביום האפליקציה בודקת אם יש גרסה חדשה ומציעה להוריד אותה. ההתקנה נעשית מעל הגרסה הקיימת, והעבודות השמורות נשארות.
  כדי שזה יעבוד, הגרסאות צריכות להיות חתומות באותו מפתח. ראו "מפתח חתימה" למטה.

## מה יש באפליקציה
- **תמונה / לוגו / PDF / SVG:** הפרדה אוטומטית לצבעים (עד 12, כמספר המחטים), והמרה לתפרי מילוי, סאטן וקו.
- **תמונת צילום / נוף:** במצב צבעוני, או במצב "קווים" – הצללה בחוט אחד.
- **הסרת רקע בבינה מלאכותית:** שלושה מודלים שרצים על המכשיר – מהיר, הכי מדויק (RMBG-1.4, בדיקה כפולה) ואנשים – עם ניקוי אוטומטי של הקצוות. בלוגו, מילים ופרטים שהבינה המלאכותית מחקה חוזרים אוטומטית.
- **טקסט בכל השפות:** עברית, אנגלית, ערבית, רוסית, סינית, יפנית, קוריאנית, הודית ועוד. יש 117 גופנים בבוחר ויזואלי (עברית: רגיל, עגול, כתב יד, כתב מחובר, סת״ם אשכנזי וספרדי אמיתיים, רש״י, כתר, שופר, אהרוני, כותרות, מעוצב; אנגלית: מסולסל, כתב יד, קלאסי, קולג׳, גותי ועוד), בחירת עובי, צורות טקסט (קשת, עיגול מלא, גל, אנכי), הטיה וריווח עם תצוגה מקדימה חיה, וגם סמלים (❤).
- **סאטן שעוקב אחרי צורת האות:** כל קו הוא פס סאטן אחד רציף.
- **רקע ומסגרת רקומים מאחורי העיצוב,** צורות מוכנות (לבבות, מגן דוד, מסגרות, פרחים, רימון ועוד), אפליקציה וקו מתאר.
- **כיוון התפר:** אוטומטי, שוכב, עומד (מלמעלה למטה), אלכסון או כל זווית.
- **עריכה:** בחירה, מחיקה, צביעה והזזה של חלקים באצבע או בחיצים מדויקים (½, 1 או 5 מ״מ), מירכוז בלחיצה, ביטול/חזרה, ומחק/החזר/מחק אזור על התמונה.
- **קובץ לכל שם:** אותו עיצוב עם שם אחר בכל קובץ.
- **התאמה למכונת SWF עם 12 מחטים:** חישוקים מוכנים, מצב כובע, ושיוך מחט לכל צבע.
- **התראות עם תיקון בלחיצה אחת:** יותר מ-12 צבעים, עיצוב גדול מהחישוק, טקסט קטן מדי, צפיפות חריגה, הרבה חיתוכים, ועוד.
- **דף הוראות:** איזו מחט רוקמת כל שלב ובאיזה צבע, מספר תפרים וזמן משוער. אפשר לשמור כתמונה או להדפיס.
- **תצוגה ותכנון:** תצוגה שנראית כמו חוט אמיתי, סימולציה של הרקמה תפר אחרי תפר, ובחירת צבע הבד.
- **קבצים קיימים:** פתיחת קובצי DST, PES, JEF ו-EXP, החלפת צבעים ושינוי גודל. גם תמונות HEIC (אייפון) ו-TIFF.

## מפתח חתימה לאנדרואיד (פעם אחת)
כדי שעדכונים יותקנו מעל הגרסה הקיימת, מוסיפים ב-GitHub שני Secrets:
**Settings ← Secrets and variables ← Actions ← New repository secret**
- `ANDROID_KEYSTORE_B64` – המפתח (base64)
- `ANDROID_KEYSTORE_PASSWORD` – הסיסמה

בלי שני ה-Secrets האלה, הבנייה עדיין עובדת, אבל כל גרסה נחתמת במפתח זמני אחר. במצב כזה כדי לעדכן צריך להסיר את האפליקציה ולהתקין מחדש.

## אתר
אותה אפליקציה עובדת גם כאתר, בלי התקנה: https://aview120-rgb.github.io/kablon-app/
האתר מתעדכן אוטומטית בכל בנייה. הבינה המלאכותית רצה גם בו על המחשב עצמו, ולא על שרת. בכניסה הראשונה הדפדפן מוריד את הגופנים והמודלים, ובכניסות הבאות הם כבר שמורים אצלו.

## פיתוח
```bash
npm ci
npm run assets     # מוריד גופנים ומודלי בינה מלאכותית (מאומתים ב-SHA-256)
npm test           # בדיקות המנוע
npm run dev        # הרצה בדפדפן
npm run electron:dev
```
הבנייה של קובץ ה-APK והתקנת ה-Windows רצה אוטומטית ב-GitHub Actions (`.github/workflows/lema-hayakara.yml`) בכל דחיפה, ובסופה נוצר Release עם שני הקבצים.
