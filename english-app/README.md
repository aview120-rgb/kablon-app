# Safa – לומדים אנגלית בעברית 🗣️

אפליקציית אנדרואיד חינמית ללימוד אנגלית לדוברי עברית, עם פרסומות של Google AdMob.

| | |
| --- | --- |
| שם בחנות | **Safa – לומדים אנגלית בעברית** |
| מזהה חבילה | `com.safaenglish.app` (אי אפשר לשנות אחרי ההעלאה הראשונה!) |
| תוכן | 9 יחידות · 29 שיעורים · 172 מילים · 5 סוגי תרגילים |
| טכנולוגיה | JavaScript + Vite → Capacitor 8 → אנדרואיד (`.aab`) |
| שרת | אין. אין חשבונות. הכל נשמר בטלפון של המשתמש |
| הכנסה | AdMob: באנר, מסך מלא (פעם ב־3 שיעורים), סרטון עם פרס |

## מה עושים עכשיו – לפי הסדר
1. **[docs/ADMOB-SETUP.md](docs/ADMOB-SETUP.md)** – לפתוח AdMob ולשים את המזהים שלך (כדי שהכסף יגיע אליך).
2. **[docs/GOOGLE-PLAY.md](docs/GOOGLE-PLAY.md)** – ליצור מפתח חתימה, לבנות את הקובץ ולהעלות ל־Google Play.
3. **[docs/LEGAL-ISRAEL.md](docs/LEGAL-ISRAEL.md)** – מה בדקנו בחוק הישראלי ומה נשאר לך למלא (שם + אימייל).

## למפתחים
```bash
npm install
npm run dev          # פתיחה בדפדפן
npm test             # בדיקות יחידה
npm run e2e          # 15 בדיקות מקצה לקצה + בדיקת נגישות
npm run android:sync # בנייה והעתקה לפרויקט האנדרואיד
```
- תוכן השיעורים: `src/data/course.js` – להוספת שיעור מוסיפים אובייקט, התרגילים נבנים לבד.
- הגדרות פרסומות: `src/config.js`
- מסמכי התכנון (11 שלבים): `replica/`
- חומרים לחנות: `store/` (צילומי מסך 1080×1920, תמונה ראשית 1024×500, טקסטים ב־`replica/launch/listing.json`)
- דף נחיתה: `site/index.html`
